Domain Dashboard

Namecheap + Cloudflare bằng API — không cần mở Chrome. Bấm Setup là tự chạy hết.

Cài đặt — Cloudflare token & Namecheap API (bấm để mở)

Cloudflare token: tạo ở Cloudflare Dashboard → My Profile → API Tokens (quyền Zone:Edit + DNS:Edit). Namecheap: bật API Access (Profile → Tools), lấy API key, whitelist IP máy này.

Preset record — lưu cấu hình để áp nhanh

VD preset "web": A @ → IP, A www → IP. Áp preset sẽ xóa hết record cũ rồi thêm mới.

Email preset — rule forward áp trong lúc Setup

Setup sẽ bật Email Routing rồi tạo các rule này (rule nào có sẵn giống hệt thì giữ). info@ nghĩa là info@<domain đang setup>, * là catch-all. Địa chỉ nhận phải bấm link xác minh trong mail thì rule mới forward được.

HTTPS preset — áp trong lúc Setup

Setup sẽ set SSL/TLS theo cấu hình này cho từng domain (bước cuối). Mặc định: SSL Flexible + Always Use HTTPS bật + Minimum TLS 1.2.

Setup theo danh sách

Dán domain cần setup đợt này (mỗi dòng 1 domain), bấm Setup — tool check từng domain: DNS chưa set thì đổi NS, rồi áp preset record, rồi email routing. Chỉ xử lý đúng các domain trong ô này, không động đến domain khác.
