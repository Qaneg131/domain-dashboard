Domain Dashboard

Namecheap + Cloudflare bằng API — không cần mở Chrome. Bấm Setup là tự chạy hết.

Cài đặt — Cloudflare token & Namecheap API (bấm để mở)

Cloudflare token: tạo ở Cloudflare Dashboard → My Profile → API Tokens (quyền Zone:Edit + DNS:Edit). Namecheap: bật API Access (Profile → Tools), lấy API key, whitelist IP máy này.

Chỉ cần khi Chrome để User Data ở chỗ khác — để Dashboard liệt kê các hồ sơ Chrome cho tab Auto-renew.

Preset record — lưu cấu hình để áp nhanh

Setup / Áp record sẽ dùng preset đang chọn ở đây.
VD preset "web": A @ → IP, A www → IP. Áp preset chỉ cập nhật record trùng tên/loại, record khác giữ nguyên.

HTTPS preset — áp trong lúc Setup

Setup sẽ set SSL/TLS theo cấu hình này cho từng domain (bước cuối). Mặc định: SSL Flexible + Always Use HTTPS bật + Minimum TLS 1.2.

Email preset — rule forward áp trong lúc Setup

Setup sẽ bật Email Routing rồi tạo các rule này (rule nào có sẵn giống hệt thì giữ, rule trùng thì xóa bớt, rule của địa chỉ khác giữ nguyên). info@ nghĩa là info@<domain đang setup>, * là catch-all. Địa chỉ nhận phải bấm link xác minh trong mail thì rule mới forward được.

Setup theo danh sách

Dán domain cần setup đợt này (mỗi dòng 1 domain), bấm Setup — tool check từng domain: DNS chưa set thì đổi NS, rồi áp preset record, rồi email routing. Chỉ xử lý đúng các domain trong ô này, không động đến domain khác.

Google Sheet — setup theo sheet

Đọc sheet từ link CSV publish (cột B Tên Domain, H Loại web, J Đã hoàn thành, L Ghi chú), từ dòng bắt đầu trở xuống. Chỉ xử lý 2 trạng thái ở cột J: "Cần set up"/"Cần setup" (sẽ setup) và "Đã set up"/"Đã setup" (bỏ qua) — viết có hay không có khoảng trắng đều nhận. Setup xong thì ghi "Đã set up" vào cột J. Đi từng hàng, xong 1 (thành công hay lỗi) mới qua hàng sau; hàng nào xung đột preset thì đưa vào mục Chờ duyệt. Với preset Web Anh Long, nếu cột L có ghi ID thì setup kèm record TXT _cf-custom-hostname = ID đó (ghi bình thường, không dấu ngoặc kép); cột L trống thì setup bình thường. Sau này đổi ID ở cột L thì đọc lại sheet sẽ tự cập nhật TXT đó. Bấm Setup lại ở mục Bỏ qua thì thử lại tối đa 3 lần, hết 3 lần vẫn lỗi thì dừng và báo lỗi.

Nhập Sheet ID + file JSON key service account thì dashboard đọc sheet trực tiếp qua Sheets API (live, sửa sheet là thấy ngay) và ghi được cột J. Chưa có key thì vẫn đọc qua link CSV publish (Google cache vài phút) + setup được, chỉ không ghi được cột J (log sẽ báo rõ). Cần: Google Cloud → bật Google Sheets API → tạo service account → tải JSON key → share sheet cho email service account quyền Editor; pip install google-auth (run.bat tự cài nếu thiếu).

Auto-renew (bằng Chrome) — bật tự động gia hạn trên Namecheap

API của Namecheap báo xong nhưng toggle trên web không đổi nên phải bấm toggle thật trên Chrome. Bước 1: bấm nút 1 để mở tab Namecheap Domain List, đăng nhập Namecheap xong. Bước 2: tick chọn domain trong bảng dưới (đổi trang hay tìm/lọc domain mới vẫn giữ nguyên các domain đã chọn, chọn thêm được), chọn cách xử lý hộp thoại Domain Privacy, bấm nút 2 — Dashboard gọi sang tool Chrome để tìm từng domain trong Domain List rồi bấm toggle Auto-Renew thật. Domain nào toggle đã BẬT rồi thì bỏ qua, không bấm (bấm sẽ tắt đi). Chỉ xử lý đúng các domain đã chọn. Muốn bật hàng loạt domain Xanh chưa có auto-renew: lọc Tình trạng = Xanh + Auto-renew = No, bấm "Chọn hết (đang lọc)" rồi bấm nút 2.

Check mail — mail của các domain Pass

Đọc từ 2 sheet xuất bản: Sheet 1 lọc domain có cột H = Pass (cột C là tên domain), Sheet 2 lấy mail theo cột Domain (cột G). Chỉ hiện mail thuộc domain Pass. Mỗi mail là 1 hàng riêng — 1 domain có nhiều mail thì hiện nhiều hàng. Mật khẩu và Mã 2FA mặc định che kín — nút mắt luôn hiện, bấm mới hiện giá trị thật, bấm lại thì che đi; nút copy chép đúng giá trị gốc kể cả khi đang che. Bộ lọc Mail VRF đọc các giá trị có thật trong cột E của sheet nên sau này thêm giá trị mới sẽ tự hiện thêm. Ghi chú chỉ lưu trong app, không ghi ngược vào Google Sheet.

Cảnh báo: 2 Google Sheet nguồn đang ở chế độ publish công khai (ai có link cũng đọc được), nên không chia sẻ link của ứng dụng này cho người ngoài.
